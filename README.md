# Platform Website Profil dan Katalog Siap Pakai untuk UMKM

Judul terkunci 2026-11-09: Pengembangan Platform Website Profil dan Katalog Siap Pakai Berbasis Web dengan Model SaaS untuk UMKM. Stack terkunci 2026-11-09: Laravel 12, PHP 8.2+.

Tugas Besar Cyber Security (individu, Pra-UTS): platform web berbasis
SaaS tempat satu UMKM mendapat satu halaman publik profil dan katalog
siap pakai (contoh: `/u/toko-abc`) dan mengelolanya dari dashboard —
tanpa membangun atau meng-host websitenya sendiri. Slice 1 yang sedang
dibangun: registrasi UMKM, login, dan dashboard per peran (vendor dan
admin UMKM).
